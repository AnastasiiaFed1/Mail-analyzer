Моніторинг ресурсів поштових клієнтів

Цей скрипт призначений для збору метрик (CPU, RAM, потоки, Context Switches тощо) поштових клієнтів під час різних сценаріїв навантаження (простій, середнє, високе).

Як почати (для Windows)

Встановіть Python: Переконайтеся, що у вас встановлений Python (рекомендується версія 3.9 або новіша).

Відкрийте термінал: Відкрийте командний рядок (cmd) або PowerShell у папці, де знаходяться ці файли.

Налаштування оточення (Обов'язково)

Щоб не засмічувати систему, краще створити віртуальне середовище та встановити туди бібліотеки:

# 1. Створення віртуального середовища
python -m venv venv

# 2. Активація середовища
venv\Scripts\activate

# 3. Встановлення необхідних бібліотек
pip install -r requirements.txt


Використання

Запустіть необхідний поштовий клієнт (наприклад, Thunderbird або Chrome з відкритим Gmail).

Запустіть скрипт:

python monitor.py


Дотримуйтесь інструкцій на екрані:

Оберіть поштовий клієнт зі списку.

Оберіть сценарій (1 - Простій, 2 - Скролінг, 3 - Пошук/Стрес-тест).

Натисніть Enter для старту.

Під час виконання скрипту (за замовчуванням 60 секунд) виконуйте в обраній програмі дії, що відповідають сценарію. По завершенню, результати будуть збережені в папці data у форматі .csv.
